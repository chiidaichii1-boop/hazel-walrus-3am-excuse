## The entry

> My buttons went on strike at 3 AM — they refuse to sign a coin whose name you can't even pronounce.

## How it works

`main.py` (Python 3, standard library only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
It reads no input, makes no network calls, and always produces the same
bytes, so the two grader runs are byte-identical.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out1 python3 main.py
cat /tmp/out1/entry.txt
```
